# 月度标保分析

- 全系统标保达成12444万元，标保达成率61.8%，标保同比负增11.6%；全年标保达成100538万元，全年标保进度53.8%，全年标保同比正增20.6%。
- 标保达成率高于70%的机构共9家，分别为新疆、天津、潍坊、云南、海南、河南、内蒙古、宁波和甘肃。
- 标保达成率低于50%的机构共有8家，分别为：贵州、安徽、山西、上海、青岛、宁夏、北京、深圳。
- 全年标保进度高于60%的机构共有7家，按进度从高到低依次为宁波、新疆、贵州、潍坊、天津、甘肃、云南。
- 全年标保进度低于45%的机构共6家，分别为安徽、海南、宁夏、青岛、北京、深圳。

# 月度价值分析

- 全系统价值达成7045，价值达成率74.1%，价值同比正增9.8%，全年价值进度54.2%，全年价值同比正增7.2%。
- 价值达成率高于85%的机构共5家，分别为河南、天津、云南、吉林、新疆。
- 价值达成率低于55%的机构共8家，分别为宁波、贵州、山西、青岛、宁夏、北京、上海和深圳。
