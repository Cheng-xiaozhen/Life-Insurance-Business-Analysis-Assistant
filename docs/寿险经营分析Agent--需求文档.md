寿险经营分析Agent -- 需求文档

摘要
寿险经营分析Agent是一款面向寿险公司经营管理与企划人员的智能经营分析助手。一方面，用户从模板库中选择报告模板（如营业区月度经营分析报告），系统自动查询经营数据、按模板的分析框架生成专业分析结论并自动绘制图表，一键导出为正式的经营分析报告；另一方面，用户也可用自然语言提问（例如"看看8月的标保达成情况""本月哪些机构人力表现好"），系统自动识别分析意图、查询经营数据、生成专业分析结论，快速获得针对性解答。


产品总流程：从知识沉淀到分析使用

[数捷系统上传加工表] → 上传历史报告 → 知识提取（报告模板 + 问题场景）→ 数据源智能映射 → 人工审核确认 → 知识使用（生成报告 / 分析问答）。

 

核心功能流程：
日常经营问答

 
 
报告生成流程（示例：月度经营检视）
本流程为"通用报告生成器"的示例。系统对知识库中的任意报告模板均按同一方式执行：用户预选模板 → 发送指令 → 提取必要参数 →（缺参则追问补充）→ 按模板板块依次分析 → 汇总输出 → 导出。

 
 
知识导入流程：历史文档知识沉淀

 

功能详细说明
### 模块 A：智能问答
#### A1. 自然语言提问

| 项目 | 说明 |
|------|------|
| 功能描述 | 用户在对话输入框中用自然语言提问经营问题，支持口语化表述、混合关键词 |
| 典型输入 | "看看5月的标保达成情况"、"本月各机构活动人力表现怎么样"、"XX 机构标保达成率排名" |
| 常用问题快速入口 | 对话框提供常用问题快捷入口（如"看看营业区本月的标保达成情况"），用户点击即自动填入并发送，无需手动输入 |
| 异常处理 | 无法识别的问句给出"换个问法"引导，并提供常见问题示例列表 |

#### A2. 分析意图识别

| 项目 | 说明 |
|------|------|
| 功能描述 | 系统自动判断提问属于哪个分析场景（如标保达成、人力排名、红黄蓝评价等），并确定需要哪些指标与数据 |
| 要求 | 识别结果需给出匹配置信度与候选项；识别模糊时可向用户确认 |

#### A3. 数据分析与结论生成

| 项目 | 说明 |
|------|------|
| 功能描述 | 系统对查询结果进行分析，生成符合经营分析语言习惯的结论要点 |
| 回答方式 | **分析问答场景**：系统根据语义匹配最合适的分析场景，使用该场景的分析思路与分析模式进行回答，**表达偏灵活**（可口语化、支持多轮追问） |
| 分析思路 | 严格按照场景中定义的步骤进行分析；仅使用场景关联指标查询到的系统数据；**严禁引入场景外的规则**；**严禁编造数据** |

#### A4. 图表自动生成

| 项目 | 说明 |
|------|------|
| 功能描述 | 系统根据分析类型自动选择合适图表并渲染，用户无需手工制图 |
| 图表类型 | 排名对比（柱状图）、分布散点（散点图）、机构综合评价（红黄蓝四象限图）、热度分布（热力图）等 |
| 交互要求 | 图表支持悬停查看数值、图例切换、导出图片 |
| 随附信息 | 每张图表附一句"怎么看"的文字说明，降低解读门槛 |

#### A5. 推理过程展示

| 项目 | 说明 |
|------|------|
| 功能描述 | 向用户展示分析的推理过程：识别到哪个场景、使用了哪些指标、按什么规则得出结论 |
| 展示形式 | 折叠式步骤面板，默认收起，可展开逐条查看 |
| 价值 | 结论可追溯、可复核；帮助新人学习分析逻辑 |

### 模块 B：报告生成
#### B1. 模板预选 + 指令驱动的报告生成

| 项目 | 说明 |
|------|------|
| 功能描述 | 用户在操作界面预先选择报告模板（如下拉选择或卡片选择），再输入生成指令（如"做一份5月的经营检视报告"）；系统从指令中提取生成报告所需的必要参数（如月份、数据范围等），按其定义的板块顺序依次执行分析并汇总 |
| 模板选择 | 模板由用户在界面上显式选择，系统不做自动匹配；切换模板即切换后续生成的报告结构 |
| 参数提取 | 系统从指令中提取必要参数（如报告周期、范围等）；指令中未提及的必要参数，系统回复用户请其补充，而非自行猜测 |
| 执行规则 | 板块内容、分析场景、所用指标、综合洞察要求均以所选模板定义为准；模板更新后，生成结果随之按新模板产出 |
| 输出 | 完整报告内容（各板块结论 + 数据表 + 图表 + 模板要求的综合评价与综合洞察） |


#### B2. 报告内容生成（按模板）

| 项目 | 说明 |
|------|------|
| 功能描述 | 报告按所选模板定义的编排结构输出内容 |
| 板块编排 | 板块顺序、标题、页内要点均由模板定义；不同模板可拥有完全不同的板块构成 |


#### B3. 报告导出

| 项目 | 说明 |
|------|------|
| 功能描述 | 一键导出所选模板对应的正式 Word 报告，格式规范 |
| 导出内容 | 按模板定义输出封面、各板块结论与数据表、综合评价、综合洞察等全部内容 |
| 格式要求 | 金额统一"万"整数、百分比保留 1 位小数、率值同比用百分点（pt）、正增长蓝/负增长红（以模板定义为准） |
| 异常处理 | 导出失败时保留当前页面内容，提示重试 |

### 模块 C：知识管理

#### C1. 历史文档知识导入

| 项目 | 说明 |
|------|------|
| 功能描述 | 用户上传历史经营分析文档，系统自动提取其中的指标引用、分析模式、分析场景、报告模板。支持 Word/PPT/PDF 格式，可一次上传多个文档（指标计算口径以数捷系统/配置化平台定义为准，不从文档提取覆盖） |
| 批次机制 | 本次上传的文档作为一个"知识提取批次"处理；导入页面**仅展示该批次的状态**（如提取中 / 提取完成 / 部分失败），不做逐项审核 |
| 审核确认 | 提取成功的批次，用户到知识管理模块**对应功能下**进行审核确认（报告模板 → C2 报告模板管理、分析场景 → C3 分析场景管理、分析模式 → C4 分析模式管理、指标引用 → C5 指标与数据源关联），审核通过后纳入知识库生效 |

#### C2. 报告模板管理

| 项目 | 说明 |
|------|------|
| 功能描述 | 维护或者审核报告模板（板块构成、各板块关联场景、格式要求等） |
| 操作 | 查看、编辑报告模板的板块与顺序 编辑报告的分析思路以及使用的指标与规则 |


#### C3. 分析场景管理

| 项目 | 说明 |
|------|------|
| 功能描述 | 维护分析场景（如"标保达成分析""新增人力分析"）。**场景的核心内容是场景内定义的分析思路**：按业务分析逻辑编排的分析步骤（如"先看全系统达成 → 再看同比 → 最后排名与预警"），以及每个步骤关联使用的指标与规则。系统执行分析时严格按照场景内的分析思路进行，仅使用场景关联指标查询到的系统数据，不引入场景外规则、不编造数据 |
| 操作 | 查看、新增、编辑、停用场景；重点维护场景内的分析思路（分析步骤编排、各步骤关联的指标与规则） |
| 要求 | 场景内分析思路变更即时生效，后续分析按新思路执行 |


#### C4. 指标与数据源关联

| 项目 | 说明 |
|------|------|
| 功能描述 | 维护系统指标及其数据来源的关联关系。指标的计算口径由上游系统（数捷系统、配置化平台）统一定义，**用户不可自定义指标计算口径**，本功能仅负责将指标与对应数据源智能关联 |
| 数据来源 | 指标数据均取自数捷系统与配置化平台，本系统通过数据源关联自动获取对应指标数据 |
| 操作 | 查看指标及其口径说明、关联的数据源；为指标配置或调整数据源关联；编辑时提示被哪些场景引用 |
| 要求 | 指标口径由上游系统定义，本系统不支持修改；数据源关联变更即时生效，不影响历史报告文件 |
